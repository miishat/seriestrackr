# Apple primary page qualification

The authorized apple-product-html-1 probe fetched two public product pages without keys, retries or AI. The ebook page exposes JSON-LD Book with author, name, EBook, inLanguage, ISBN and datePublished. The audio page exposes Audiobook, author, name and datePublished, plus a product LANGUAGE badge explicitly saying English. These fields can close the API language gap using the same storefront edition ID. This is a retrieval amendment; live scope remains pending.

Implement a strict bounded public Apple product page normalizer and collection stage before optional AI. Use only https://books.apple.com product URLs obtained from normalized Apple API evidence, with the same numeric edition ID and requested two-letter storefront country. Reject credentials, ports, other hosts, redirects and malformed paths. Retrieve text/html with the shared 1MiB and 20second limits, cancellation and 1.1second Apple queue. Count every started HTML call against the existing total12 Apple calls, not an additional quota. No account cookies, retries, external links or browser storage. Limit to6 pages, prioritize requested market and one candidate per requested format before additional alternatives, then fallbacks. Preserve missing-data failures and original evidence.

Parse only bounded application/ld+json scripts. Require a unique product Book or Audiobook object, explicit supported bookFormat for ebook, literal author and name equal to the retrieved Apple record, matching canonical product URL ID and country when present. Ignore Organization, recommendations, localization scripts and work-level metadata. Exact English inLanguage codes qualify ebook; audiobook without inLanguage needs a uniquely parsed product book-badge group LANGUAGE with English caption. Contradictory language data rejects qualification. Footer English locale is never edition language. Dates must be valid exact days, attached to this product, and agree with API dates for the same edition; contradictory dates remain a conflict, never replace one silently.

Keep exact canonical work title matching. A narrowly defined audio label may match a resolved English identity when its literal title is exactly canonical title plus '(Unabridged)', or canonical title plus ': REQUESTED SERIES, Book REQUESTED POSITION (Unabridged)'. Require matching author and retain the literal title and relationship statement in citations. Permit series aliases already generated only from the request, never arbitrary subtitle removal or fuzzy matching. Wrong series/position, abridged, translated subtitles and companions reject. No page-based identity guessing; seed identity comes from independent validated evidence. A valid ebook ISBN may establish the exact catalog/storefront join under the reviewed ISBN rules, preserving canonical and language citations.

Emit source text containing only the qualified product fields and literal badge/relationship evidence, with a separate source ID per country/edition; link the actual product page. Use existing deterministic policy and conflict grouping, retain per-format market preference/fallback. Raw HTML remains transient in product runtime and never reaches app storage. The isolated research HTML files remain ignored evidence. Hardcover raw dates remain quarantined.

TDD covers language badges versus footer, conflicting JSON-LD, unknown/malformed dates, wrong edition/host/country, JSON-LD recommendations, wrong author/format, conservative audio labels, language/date conflict, cancellation, MIME/size/redirect guards, counted12 cap, preferred/fallback ordering, no-key/noAI behavior and an actual pipeline fixture yielding traceable book/audio dates. Independently review and validate before authorized live testing. Do not migrate library/UI until original live gate succeeds or supported scope is explicitly recorded under the specification.

Evidence: [Apple ebook product](https://books.apple.com/ca/book/the-strength-of-the-few/id6743716497) and [Apple audiobook product](https://books.apple.com/ca/audiobook/the-strength-of-the-few-hierarchy-book-2-unabridged/id1852118863).
